# Module 7 – Oligopoly and Game Theory: Revised Outline

**Purpose of this file.** Proposed slide-by-slide plan for rebuilding
`Module 7.pptx` (87 slides, 4:3, four masters) into the revised widescreen
format (`Module 7 - Revised.pptx`). This is a **reformat, not a rewrite**:
original titles, bullet wording, examples, and pedagogy are preserved;
only the visual layer changes. Each entry shows the slide number (kept
1:1 with the source), a tag, and the planned treatment.

**Net change: none — 87 slides in, 87 slides out.** The six recurring
"OUTLINE of Module 7" slides (10, 16, 28, 37, 47, 54) are each replaced
*in place* by a new-style section divider highlighting the current
section, so numbering, speaker notes, and poll/video splices all stay
aligned.

**Tags.** `[KEEP]` = reformat only (chrome, fonts, palette).
`[NATIVE]` = chart/table/diagram rebuilt as native PowerPoint shapes.
`[DIVIDER]` = recurring outline slide → new-style section divider.
`[POLL]` / `[VIDEO]` = live content, spliced from the source deck in
phase 3 (OOXML surgery). `[HIDDEN]` = rebuilt and kept hidden.

---

## Global treatments (apply to every slide)

- 4:3 → **widescreen 13.33 × 7.5"**; four masters → **one master**;
  Calibri everywhere; navy/gold/gray palette; navy top bar with
  `Module 7 · Part · Section` tag; action-title chrome; thin rule +
  gold accent strip; live slide-number footer fields.
- All formulas → **native OMML** (Cambria Math): P = 100 − Q_M,
  reaction functions Q_A = 45 − 0.5·Q_B, P_A = 200 + 0.25·P_B, etc.
- All charts/diagrams/tables → **native shapes** (navy axes with arrow
  heads, connectors, Bézier freeforms, white backing card + grouped
  shade for tables). No screenshots except genuine photos/logos/polls.
- **Payoff matrices** follow the game-theory conventions: column player
  name on top (accent color), row player rotated at left (reserved
  concept color), white cells with navy borders, payoffs in the two
  players' colors, best-response arrows + circles, Nash oval as the
  animated finale.
- Animations: fade ~0.5 s on click, story order, first bullet with the
  slide, takeaway bar last (phase 3, after grouping).
- Photos: rounded corners + soft shadow, caption above / source below.
- Original speaker notes preserved verbatim (they are substantive).
